# Street Life 3D

An offline Android street-life game prototype. Explore an isometric city, avoid
buildings, find the gold mission marker, and tap **ACTION** to earn cash.

## Build

Open this project in Android Studio, or run:

```sh
gradle assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.
An installable debug build is also included as [`StreetLife3D.apk`](StreetLife3D.apk).

## Controls

- Drag the left virtual joystick to move.
- Tap **ACTION** when near the gold marker to complete a mission.

Requires Android 6.0 (API 23) or newer. The game does not require network access.
